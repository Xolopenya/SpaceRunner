# Space Runner

Browser-based 3D space endless runner developed with Three.js, TypeScript, and Vite.

## Codex starting point

Read `AGENTS.md`, then paste or point Codex to `docs/CODEX_MASTER_PROMPT.md`.

The game itself has not yet been scaffolded. Let Codex create the Vite project and scripts within this repository, then update this README with tested commands.
