# Space Runner

Браузерный 3D-раннер: корабль летит вперёд сам, игрок выбирает путь между астероидами, обломками и станциями с проёмами. Цель — продержаться дольше и улучшить рекорд расстояния.

[Играть в Space Runner](https://xolopenya.github.io/SpaceRunner/). Публикация из main проверена в Chrome: запуск, Phase 2, пауза, рестарт и настройки. Подробности — в [проверке поставки](docs/assignment-002/DELIVERY_CHECKLIST.md).

## Управление
WASD или стрелки — движение по горизонтали и вертикали. На телефоне — перетаскивание по экрану. P/Escape и кнопка Pause останавливают полёт; Resume продолжает его. В паузе можно начать заново. Корабль выдерживает три попадания, после удара ненадолго становится неуязвимым. После гибели доступен повторный запуск. Рекорд сохраняется в браузере.

## Что работает
Обычный Play запускает непрерывное поле обломков с несколькими видами встреч и станциями с меняющимися проёмами. На 500 м включается опасный сектор: скорость получает множитель 1.08, дополнительные интервалы между обычными встречами убираются. Фаза показана в HUD. Master, Music и SFX регулируются независимо в Sound settings и сохраняются после перезагрузки; M включает mute.

Самонаводящаяся мина остаётся DEV-экспериментом и в публичную игру не включена: у неё сохраняются пропуски публикации и длинные кадры. Система проверки маршрутов также иногда отклоняет обычные секции. Физические телефоны пока не проверены. Пять минут непрерывного выживания не гарантируются; несколько запусков подходят для демонстрации.

## Локальный запуск
Нужны Node.js 24 и npm. После установки зависимостей:

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
npm run preview
```

Откройте адрес, который напечатает Vite. Для проверки сборки под путём Pages: node scripts/assignment-browser.mjs. Установленный Chrome требуется для браузерных тестов. Трёхминутные проверки модели: node --experimental-strip-types scripts/assignment-audit.mjs.

## Код
TypeScript, Three.js и Vite; интерфейс — HTML/CSS. src/game.ts связывает ввод, модель, UI, звук и рендер. src/core содержит движение, столкновения и валидатор; src/release — параметры фаз и публичную модель. src/experiments/mixed-flow и structure-variants предоставляют принятый генератор и геометрию станций. src/audio — звук и настройки.

Архитектура, сценарий защиты и ответы: docs/assignment-002/. Источники моделей и лицензии: [docs/ASSETS.md](docs/ASSETS.md). Основные модели — Kenney Space Kit CC0; геометрия станций оформлена в проекте. Сервер, аккаунт и Yandex SDK для запуска не нужны.
