# Space Runner

[Играть в браузере](https://xolopenya.github.io/SpaceRunner/) · [Исходники](https://github.com/Xolopenya/SpaceRunner)

Браузерная 3D-аркада про полёт через космический мусор. Корабль движется вперёд сам; игрок маневрирует по горизонтали и вертикали, проходит проёмы станций и старается пролететь дальше. Конечного уровня нет.

## Как играть

У корабля три единицы прочности. Повреждения получают и корпус, и оба крыла. После удара действует короткая неуязвимость, чтобы одно препятствие не сняло всю прочность сразу. Повреждения видны на корабле; разные столкновения сопровождаются эффектами и звуком. После гибели короткая пропускаемая сцена разрушения переходит к результатам.

В Mixed Flow чередуются астероиды, обломки и крупные секции станций с пятью положениями прохода. Самонаводящаяся мина следит за текущим положением корабля, но сохраняет инерцию: её можно выманить и обойти сменой направления. Красный сигнал предупреждает об угрозе; одновременно активна не более одной мины.

Бирюзовые Energy Fragments необязательны. Их можно собрать корпусом или крылом; мягкая помощь подбора и короткое магнитное притяжение облегчают близкий пролёт. ENERGY считается отдельно от дистанции и показывается в итогах забега. Рестарт обнуляет текущий счётчик.

В итогах главным результатом остаётся дистанция; новый личный рекорд выделяется надписью NEW PERSONAL BEST и сравнением с предыдущим. Равный результат новым рекордом не считается. Лучший результат сохраняется в браузере. **Fly again** сразу начинает новый забег, **Back to menu** возвращает в главное меню, сохраняя рекорд и настройки звука.

На 500 метрах начинается Phase 2: скорость повышается на 8%, а следующие встречи становятся чаще. Камера Hybrid Chase следует за перемещением корабля. Разреженные дуги и нити Combined Fragmented Warp Field помогают ориентироваться у границ; проёмы станций остаются свободными. Препятствия плавно появляются вдали.

## Управление

| Действие | Управление |
| --- | --- |
| Движение | WASD или стрелки |
| Сенсорный экран | Коснуться игрового поля и вести палец |
| Мышь | Зажать левую кнопку на игровом поле и перетаскивать; клики по кнопкам интерфейса |
| Пауза / продолжение | P, Esc, Pause / Resume |
| Новый забег | Restart в паузе или Fly again после гибели |
| Возврат в меню | Back to menu на экране результатов |
| Пропустить сцену гибели | Skip, Space, Enter или Esc во время сцены |
| Звук | M; Sound settings в меню и паузе |

В главном меню есть фоновая музыка: она включается после клика или клавиши, с учётом запрета браузера на autoplay. Master, Music и SFX регулируются отдельно; громкость и mute сохраняются. Пауза и потеря фокуса останавливают игровой звук; рестарт использует тот же AudioContext.

Оригинальная электронная партитура развивается на протяжении 64 секунд: атмосфера, басовый пульс и ритмический слой плавно следуют текущей секции полёта. Двигатель реагирует на реальную скорость и манёвры; астероиды, металл, станции и мины звучат по-разному. При повреждении изредка слышны электрические сбои.

Для столкновений используются восемь выбранных CC0-семплов с тихими корпусными/электрическими слоями. При ошибке загрузки сохраняется процедурный звук. Источники и обработка описаны в [ASSETS](docs/ASSETS.md).

Кристаллы иногда образуют тройки: прямую дорожку, плавный изгиб или ряд в стороне от текущего курса. Между ними 22 метра; точный сбор требует выбранной траектории. Частота возможностей немного повышена, рост числа наград ограничен. Помощь подбора вокруг корпуса и крыльев увеличена на 12,5%, а размер самих кристаллов сохранён.

## Локальный запуск

Нужны Node.js 22.12+ и npm.

```bash
npm ci
npm run dev
```

Обычно игра доступна по http://127.0.0.1:5173/.

```bash
npm run typecheck
npm run test
npm run build
npm run test:browser
npm run preview
```

Для браузерных тестов нужен установленный Chrome. Production-файлы находятся в dist/. GitHub Actions собирает игру с базовым путём /SpaceRunner/ и публикует её через существующий Pages workflow. Текущий deployed commit можно проверить в /SpaceRunner/release.json.

## Устройство и ограничения

Three.js, строгий TypeScript, Vite и HTML/CSS; без серверной части. Game связывает IntegratedModel, ввод, HUD, World и звук. Модель использует общий составной коллайдер корабля, Mixed Flow, адаптивную мину и проверку безопасных траекторий до атомарной публикации. [Архитектура](docs/assignment-002/ARCHITECTURE.md) · [История изменений](CHANGELOG.md) · [Четыре очных плейтеста](PLAYTEST_NOTES.md) · [Проверки RELEASE-007](docs/review/RELEASE-007/OWNER_PLAYTEST_GUIDE.md).

Игровые факты доставляются через типизированные события FEEDBACK-001A в общий координатор VFX, SFX, камеры и HUD. [Устройство отклика](docs/review/FEEDBACK-001A/ARCHITECTURE.md) · [Проверки](docs/review/FEEDBACK-001A/TESTING.md).

FEEDBACK-001B добавляет устойчивые повреждения корпуса, разные реакции препятствий и короткую последовательность гибели перед результатами. Её можно пропустить кнопкой, Space, Enter или Esc; reduced motion сокращает длительность. [Отчёт и визуальная проверка](docs/review/FEEDBACK-001B/REPORT.md).

FEEDBACK-001B1 полирует поле временной защиты, детонацию мины и разрушение корабля. Игровые правила и управление сохранены. [Сравнение эффектов и проверки](docs/review/FEEDBACK-001B1/REPORT.md).

Записанные звуки столкновений из FEEDBACK-001C1 одобрены владельцем. [Исторический отчёт C1](docs/review/FEEDBACK-001C1/REPORT.md).

FEEDBACK-001C2 заменяет отвергнутые направляющие редкими цепочками кристаллов и небольшой настройкой подбора. Камера, управление, препятствия, музыка и одобренные эффекты сохранены. [Устройство и сравнение баланса](docs/review/FEEDBACK-001C2/BALANCE-COMPARISON.md).

Текущий вертикальный срез включает FEEDBACK-001D-C: читаемый HUD без наложения сообщений, подсказки по фактическому способу ввода, новый рекорд и навигацию после забега. [HUD](docs/review/FEEDBACK-001D-B/REPORT.md) · [Результаты](docs/review/FEEDBACK-001D-C/REPORT.md). Это этап для учебной сдачи, а не завершённая игра: экономика улучшений, окончательный баланс и новые сложные комбинации препятствий ещё не готовы.

Если планировщик не успевает подтвердить безопасную встречу, секция пропускается. При редком рендере (особенно 10 Гц) пропусков больше; это не разрешает появление непроверенной мины. Возможны отдельные задержки кадров и холодная компиляция шейдеров. Проверены настольный Chrome и мобильные размеры экрана; физические телефоны пока не проверены.

Различимость технических обломков и предметов сбора остаётся открытой UX-задачей. Сообщение о длительных промежутках без метеоритов пока не подтверждено как ошибка генератора; требуется воспроизведение. Субъективное улучшение подбора отмечено владельцем, повторный тест первоначальных домашних участников не подтверждён.

## Ресурсы

Основные модели — Kenney Space Kit, CC0. Модель мины — 3D Assets, CC0. Станционные конструкции и звуковые эффекты созданы для проекта. Локальные шрифты и остальные лицензии перечислены в [docs/ASSETS.md](docs/ASSETS.md); уведомления входят в сборку.
