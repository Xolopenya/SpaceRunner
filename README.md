# Space Runner

[Играть в браузере](https://xolopenya.github.io/SpaceRunner/) · [Исходники](https://github.com/Xolopenya/SpaceRunner)

Браузерная 3D-аркада про полёт через космический мусор. Корабль движется вперёд сам; игрок маневрирует по горизонтали и вертикали, проходит проёмы станций и старается пролететь дальше. Конечного уровня нет.

## Как играть

У корабля три единицы прочности. Повреждения получают и корпус, и оба крыла. После удара действует короткая неуязвимость, чтобы одно препятствие не сняло всю прочность сразу. Лучший результат по дистанции сохраняется в браузере.

В Mixed Flow чередуются астероиды, обломки и крупные секции станций с пятью положениями прохода. Самонаводящаяся мина следит за текущим положением корабля, но сохраняет инерцию: её можно выманить и обойти сменой направления. Красный сигнал предупреждает об угрозе; одновременно активна не более одной мины.

Бирюзовые Energy Fragments необязательны. Их можно собрать корпусом или крылом; мягкая помощь подбора и короткое магнитное притяжение облегчают близкий пролёт. ENERGY считается отдельно от дистанции и показывается в итогах забега. Рестарт обнуляет текущий счётчик.

На 500 метрах начинается Phase 2: скорость повышается на 8%, а следующие встречи становятся чаще. Камера Hybrid Chase следует за перемещением корабля. Разреженные дуги и нити Combined Fragmented Warp Field помогают ориентироваться у границ; проёмы станций остаются свободными. Препятствия плавно появляются вдали.

## Управление

| Действие | Управление |
| --- | --- |
| Движение | WASD или стрелки |
| Сенсорный экран | Коснуться игрового поля и вести палец |
| Пауза / продолжение | P, Esc, Pause / Resume |
| Новый забег | Restart в паузе или Replay после гибели |
| Звук | M; Sound settings в меню и паузе |

Музыка включается после взаимодействия с меню. Master, Music и SFX регулируются отдельно; громкость и mute сохраняются. Пауза и потеря фокуса останавливают игровой звук; рестарт использует тот же AudioContext.

## Локальный запуск

Нужны Node.js 22.12+ и npm.

```bash
npm ci
npm run dev
```

Обычно игра доступна по http://127.0.0.1:5173/.

```bash
npm run typecheck
npm run test
npm run build
npm run test:browser
npm run preview
```

Для браузерных тестов нужен установленный Chrome. Production-файлы находятся в dist/. GitHub Actions собирает игру с базовым путём /SpaceRunner/ и публикует её через существующий Pages workflow. Текущий deployed commit можно проверить в /SpaceRunner/release.json.

## Устройство и ограничения

Three.js, строгий TypeScript, Vite и HTML/CSS; без серверной части. Game связывает IntegratedModel, ввод, HUD, World и звук. Модель использует общий составной коллайдер корабля, Mixed Flow, адаптивную мину и проверку безопасных траекторий до атомарной публикации. [Архитектура](docs/assignment-002/ARCHITECTURE.md) · [История изменений](CHANGELOG.md) · [Проверки RELEASE-007](docs/review/RELEASE-007/OWNER_PLAYTEST_GUIDE.md).

Если планировщик не успевает подтвердить безопасную встречу, секция пропускается. При редком рендере (особенно 10 Гц) пропусков больше; это не разрешает появление непроверенной мины. Возможны отдельные задержки кадров и холодная компиляция шейдеров. Проверены настольный Chrome и мобильные размеры экрана; физические телефоны пока не проверены.
