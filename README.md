# Space Runner

**Space Runner** — небольшая браузерная 3D-аркада про полёт через космический мусор. Корабль летит вперёд сам, а тебе нужно уводить его от астероидов, обломков и повреждённых секций станций. Чем дальше пролетишь, тем лучше результат. Конечного уровня нет — забег заканчивается, когда корабль получает слишком много повреждений.

**[Играть в браузере](https://xolopenya.github.io/SpaceRunner/)** · [Исходный код на GitHub](https://github.com/Xolopenya/SpaceRunner)

## Как играть

Управляй кораблём по горизонтали и вертикали, заранее выбирай свободный путь и следи за приближающимися препятствиями. Особенно внимательно проходи крупные обломки станций: в них есть отверстия, и положение прохода меняется от встречи к встрече.

У корабля **три единицы прочности**. После столкновения он на короткое время становится неуязвимым, чтобы одно препятствие не сняло весь корпус сразу. Когда прочность закончится, можно начать новый забег. Лучший результат по дистанции сохраняется в браузере.

На отметке **500 метров** начинается **вторая фаза — опасный сектор**. Корабль ускоряется на 8%, а встречи с препятствиями становятся чаще. Текущая фаза отображается на экране, при переходе появляется короткое уведомление.

## Управление

| Действие | Как выполнить |
| --- | --- |
| Двигаться влево, вправо, вверх и вниз | `WASD` или стрелки |
| Управлять на сенсорном экране | Коснуться игрового поля и вести палец в нужную сторону |
| Поставить на паузу / продолжить | `P`, `Esc` или кнопка **Pause / Resume** |
| Начать заново | **Restart** в меню паузы или после завершения забега |
| Выключить или включить звук | `M` |

## Что есть в игре

- **Непрерывное поле препятствий.** Астероиды и разные виды космических обломков распределены по глубине, а не стоят одинаковыми рядами. Во время забега чередуются более спокойные и напряжённые участки.
- **Крупные конструкции.** Среди обычного мусора встречаются повреждённые секции станции с проходами. Отверстия могут находиться в разных частях конструкции, поэтому иногда приходится заметно менять траекторию.
- **Две фазы сложности.** После 500 метров меняются именно скорость и частота встреч, а не только надпись на экране.
- **Оформление и звук.** Космический фон, эффекты двигателя и столкновений, фоновая музыка, меню, игровой HUD и экран завершения забега.
- **Настройки звука.** Отдельные регуляторы общей громкости (**Master**), музыки (**Music**) и эффектов (**SFX**). Музыка в меню включается после клика или нажатия клавиши; громкость можно сразу проверить в Sound settings. Выбранные значения сохраняются после перезагрузки страницы.

## Как запустить на своём компьютере

Понадобятся **Node.js 22.12 или новее** (рекомендую актуальную поддерживаемую версию) и npm.

```bash
# Установить зависимости
npm ci

# Запустить локальный сервер разработки
npm run dev
```

Открой адрес, который появится в терминале, обычно `http://127.0.0.1:5173/`.

Чтобы проверить проект и собрать версию для публикации:

```bash
npm run typecheck
npm run test
npm run build
npm run preview
```

Готовая сборка появляется в папке `dist/`. Для браузерных автотестов используется `npm run test:browser`; для них нужен установленный браузер Playwright. Публикация сайта на GitHub Pages выполняется через GitHub Actions.

## Как устроен проект

Игра написана на **TypeScript** с использованием **Three.js** для 3D-графики и **Vite** для разработки и сборки. Меню и HUD сделаны на HTML/CSS.

- `src/game.ts` — связывает игровой цикл, управление, интерфейс, звук и отрисовку.
- `src/core/` — движение корабля, столкновения и проверка безопасных траекторий.
- `src/release/` — правила публичного режима и переключение игровых фаз.
- `src/experiments/mixed-flow/` и `src/experiments/structure-variants/` — генерация смешанного поля и крупных конструкций; их принятые механики используются в обычной игре.
- `src/audio/` — музыка, эффекты и управление громкостью.

Более подробное описание находится в [`docs/assignment-002/ARCHITECTURE_NOTES.md`](docs/assignment-002/ARCHITECTURE_NOTES.md). История разработки — в [`CHANGELOG.md`](CHANGELOG.md).

## Что пока не вошло в публичную версию

Мы отдельно экспериментировали с **движущимися космическими минами**: пробовали прямолинейное и диагональное движение, захват цели и настоящее самонаведение с инерцией. Эти прототипы есть в материалах разработки, но при обычном нажатии **Play** мины **не появляются**. Их ещё нужно доработать по производительности и частоте появления.

Генератор иногда пропускает секции, если не может подтвердить безопасный путь через препятствия. На отдельных устройствах возможны краткие задержки кадров. Игра проверялась в настольном браузере и мобильных размерах экрана, но полноценные испытания на физических телефонах пока не проводились.

A/B-сравнение: `?debug=visuals&boundaries=warp&reveal=seamless&seed=42`; переключатели `legacy/warp` и `legacy/seamless` работают только в DEV. Камера Hybrid Chase, управление и игровые правила сохранены. Инструкция: [`OWNER_PLAYTEST_GUIDE.md`](docs/review/GAMEPLAY-005B/OWNER_PLAYTEST_GUIDE.md). Изменения не слиты в main и не опубликованы.

## Модели и лицензии

Основные 3D-модели взяты из **Kenney Space Kit (CC0)**. Геометрия крупных секций станции создана для проекта. Подробности об используемых материалах и их происхождении записаны в [`docs/ASSETS.md`](docs/ASSETS.md).

Для игры не нужны регистрация, отдельный сервер или установка приложения — достаточно современного браузера.
