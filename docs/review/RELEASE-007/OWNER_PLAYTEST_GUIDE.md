# Проверка владельцем RELEASE-007

Откройте https://xolopenya.github.io/SpaceRunner/ без debug-параметров. После взаимодействия с меню проверьте музыку,Master/Music/SFX и mute. Нажмите Launch. Камера должна следовать за кораблём;по краям видны разреженные дуги/нити Mode C без старых непрерывных rails и без селекторов экспериментов.

WASD/стрелки двигают корабль по X/Y;на сенсорном экране ведите палец по полю. Корпус и оба крыла получают урон;после удара есть неуязвимость. Бирюзовые Energy Fragments собираются корпусом/крылом и увеличивают отдельный ENERGY. Красная мина преследует текущее положение с инерцией:выманите её и измените направление. Проходы станции могут быть в пяти положениях.

Долетите до500м:появляется Phase2,скорость+8%,следующие встречи чаще. Проверьте pickup после перехода. P/Esc/Pause,Resume и Restart должны сохранять/сбрасывать состояние правильно. После гибели показываются дистанция/рекорд/ENERGY;Replay начинает новый забег.

Версия публикации: /SpaceRunner/release.json. Её commit должен совпадать с MAIN COMMIT и Actions run в финальном отчёте. Если браузер держит старые файлы,обновите страницу с перезагрузкой кеша;нельзя считать localhost доказательством публикации.

Ограничения:при редком рендере возможны более длинные разреженные участки из-за безопасного отказа планировщика. На отдельных устройствах возможны задержки кадров;физические телефоны не проверены. Если заметите исчезновение mine warning,дублирование ENERGY,нерабочую паузу или воспроизводимый crash,зафиксируйте версию,дистанцию и действия.

Архив:project_snapshot — точный HEAD;changes — бинарный патч от прежнего main;logs — проверки,полные истории ввода,cadence/replay/performance и deployment receipts;screenshots/videos — настоящие local production и public кадры. QA использует воспроизводимый seed и реальные шаги ввода,а не подставленные объекты. Источник,публичный main и финальный metadata проверяются отдельно.

Воспроизведение:Node22.12+,Chrome,локальный Playwright ffmpeg для видео. npm ci --ignore-scripts;node scripts/release-verify.mjs;node --experimental-strip-types scripts/release-scenarios.mjs;node scripts/release-capture.mjs;node scripts/release-performance.mjs. После успешного Pages deployment:node scripts/release-capture.mjs --live. Публикация выполняется только разрешённым Git-процессом,не этим guide автоматически.
