# Coupled validation and publication

Every branch contains real Ship XY/velocity/time/distance plus immutable `AdaptiveMineState`: ID, tick, XY, velocity, acceleration, current target and phase. A branch step advances the unchanged Ship and forward clock first, then invokes the same pure controller with that branch's Ship endpoint. Collision tests use both interval endpoints. The descriptor is shared immutable configuration; child state is replaced, never mutated in a shared predictor. Fork tests demonstrate divergence without modifying the parent or sibling.

Pruning keys retain the historical Ship bins and append mine ID/tick/phase and XY/velocity bins. Exact states and replay are unquantized. Acceleration and target need not be key fields because the next update derives them from current Ship/velocity/config; history influences future motion through the retained mine pose and velocity. Feedback cannot be represented by a seed-only mine path.

For a new mine, actual-root resolution constructs a canonical complete transaction with initial observation/config/version and deterministic ID. Fresh-root matching rejects a different player state, input, time or distance. For a committed mine, current feedback state is mandatory and checked for identity, phase/tick, finite values, bounded velocity/acceleration and reachability bounds. It comes from the authoritative source, not a forecast. All known static geometry participates in both search and replay. Unknown/invalid metadata, a second mine or a wreck in the same transaction fails structural admission.

The proposal policy first follows existing static-field goals; after preceding static hazards have passed it can rank a bait-side goal and a reversal132ticks before the depth plane. This is a search proposal only. It does not steer the live mine/player or certify a prescribed future path. An initial search using only old Y-corner ranking failed to find a route; retained diagnostic logs show that failure. Changing the ranking, rather than expanding budgets, recovered the tested full-beam route. Publication still accepts only a fresh exact coupled simulation plus independent full replay.

Each accepted witness is additionally replayed by a separately created replay job from its complete immutable context. It initializes its own controller state and responds to its own Ship/input sequence; it never uses a recorded future mine path. It checks the full field without search pruning and matches witness hash.1962additional replays cover accepted matrix/grid/probe/live-publication records in the precommit benchmark. This is independent execution of the model, not an independent architecture review or proof for arbitrary player inputs.

The runtime remains fail-closed for zero budget, cancellation, invalid parameters, missing feedback, inadequate warning, stale actual roots and collision on replay. Earlier certificates can suggest controls but cannot authorize a changed controller or field. A candidate is published only after the current complete transaction and ownership reservations pass; rejected extensions leave committed geometry intact.
