# Adaptive homing DEV experiment

Approved baseline: `d82181351a62d0600716142b9a0ad972f5613ca1`. Branch: `feature/gameplay-003c4-adaptive-homing-mine`. The owner rejected frozen Target-Lock after playtesting: observing a point once and ignoring later movement did not deliver pursuit. Target-Lock remains a comparison selector. This experiment adds authoritative feedback; it does not promote a mechanic to production.

`src/experiments/adaptive-homing/` separates settings, pure controller, coupled prediction/CCD, canonical transaction geometry, authoritative source, model adapter and presentation. `main.ts` selects it only inside the existing DEV moving-mine import path. Existing Ship, GameModel, config, controls, camera, forward progression, damage, audio, VFX, assets, field generator, encounter choices and frequency are preserved. No dependency, Worker, new asset or collectible was introduced.

The model advances Ship at120Hz, then time/distance, then field motion. `AdaptiveSource.advance` receives the actual end-of-step Ship observation and advances the single mine once. Slots read previous/current authoritative poses. GameModel performs swept contact using both bodies' interval endpoints. Renderer reads the current slot/state; the cached trail contains recorded past states only. Pause performs no simulation update; restart clears controller, bounded960-state trace and encounter metadata while retaining fixed render/pool resources.

Shared planning contracts gain optional feedback state, root binding, geometry prediction/steering hooks and metrics. Historical callers omit these fields. Feedback state is immutable and copied with each FlightState. The predictor holds only an immutable descriptor, not a mutable path. Quantized deduplication includes mine identity, tick, phase, XY and velocity. The state itself is never rounded.

At the existing scheduled publication event the source resolves controller version, configuration, identity and initial state from the actual root. Fresh full-field coupled search and independent replay run before atomic ledger/pool admission. An earlier certificate supplies a proposal only. No future mine trajectory is committed. A subsequent candidate includes the current authoritative state of the already-committed mine. Forecast-only scheduler APIs explicitly reject feedback roots rather than silently dropping state.

The source retains the original6-cell mine ownership span, ambient payload, terminal reservation, one-known-mine limit and exclusion of a wreck in the same mine transaction. Unsuccessful certification omits the mine or falls back through the existing bounded session; visible geometry is never erased to make a route pass. Logical mine state can outlive a contact until normal ownership retirement, so diagnostics distinguish logical updates from active/rendered pursuit.
