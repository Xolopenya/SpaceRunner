# Collision, ownership and determinism

Coordinates: X horizontal, Y vertical, ship at Z=0. An object's rendered Z is `run.distance - proposal.passDistance`. Production remains fixed at 120Hz. `ReleaseModel.step` snapshots previous X/Y/distance, calls the unchanged inherited motion/hazard simulation, then updates fragments for the interval actually traveled, even while hull invulnerability is active. Invalid dt and paused/disposed simulation do not move distance or collect.

For each active slot, relative endpoints are `(previousShipX-p.x, previousShipY-p.y, p.passDistance-previousDistance)` and the equivalent new endpoint. Existing `sweptSphereHit` computes closest approach over the complete segment using combined radius .42+.32=.74. This includes lateral motion and forward crossings between endpoints. Visual rotation does not alter the sphere. Tangent contacts count. A miss at lateral .741 does not. Direct crossing stress includes a 19-unit step; actual Phase 2 test uses the real 36.72 speed/120Hz interval.

`FragmentRun` in each `ReleaseModel` is the sole logical owner. Proposed points are temporary immutable values. Successful placement marks one reusable slot active. Only the publication hook can activate it; monotonic firstCell prevents duplicate section processing. Collection changes it to collected, increments count once and removes the proposal reference immediately. Uncollected objects retire at +8 units behind the ship and remove the proposal. Inactive slots hold no stale object identities. Restart/dispose clear all slots, cadence, counters and feedback. Eight slots and scalar statistics are bounded; no lifetime ID/tombstone array grows forever.

`FragmentView` only reads this state. World owns its lifetime, calls reset on normal restart and disposes it with World. It preallocates eight groups and a burst, using three shared geometries and four materials including the burst clone. ResourceOwner tracks unique resources and disposes each exactly once. No per-spawn geometry, texture or material allocation. Visuals and burst use model.elapsed so pause freezes them.

AudioManager consumes count changes once, including while muted/locked, so unmuting cannot replay a stale pickup. Existing graph voice limits and native node cleanup apply. HUD and audio are read-only observers; distance/best storage receives only the original distance score.

Same seed **and actual input/state history** reproduce placements, collision outcomes and counter. A new movement history can change accepted sections and collectible locations. The deterministic test replays the same real 1100m history after reset and compares exact proposal arrays. A counterfactual run with placement disabled receives identical inputs; ship state, distance, hull, committed/omitted counts and witness hashes match at every step. Existing collision/Ship/GameModel/planner source guard assertions remain unchanged.

Tests cover pickup/miss/edge/lateral/high-speed, simultaneous damage, protected-hull pickup, all five station apertures, rejection of walls/late/bounds/overlapping points, pause/reset, ownership, determinism, original witnesses and fifty resource-pool resets. Browser production test uses ordinary Play, deterministic test entropy and real keyboard DOM events through InputManager, without a query or model seam. Its clock is controlled for reproducible simulation; evidence videos use real wall-clock rendering separately.
