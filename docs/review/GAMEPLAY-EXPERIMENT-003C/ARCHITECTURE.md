Baseline: `41812b61f23aaeca5295b4112ed75b60c1e78897`, verified in local main, cached origin/main and GitHub main before branching. Branch: `feature/gameplay-003c-moving-space-mine`. Review and owner playtest remain required before merge.

The new `experiments/moving-mine/` modules supply one seeded content overlay, one linear trajectory, one spherical profile, a prediction subclass, a gameplay collision subclass, a cached GLTF asset owner and a view. Existing mixed-flow director history, four ordinary families, complete native payloads and station wrecks remain available. There is no second spawn loop.

RuntimeEncounterSource now optionally receives the actual proposal clock and supplies an authoritative pose. RuntimeObstacleField checks the previous fixed-step pose, updates XY from the shared pure function, and publishes all slots atomically using the current pose. Immutable planned geometry retains its original anchor and absolute motion clock. Collision corrects the previous relative X endpoint passed by the unchanged GameModel; current hull, invulnerability, score and update ordering remain intact.

The existing geometry extension supplies MinePrediction to beam search, constructive actual-root search and independent replay. Broad-phase depth culling remains sound because the mine has no axial movement. Motion metadata is included in witnesses/hashes, copied/frozen in validator/ledger snapshots and compared in exact known-field identity. Unknown or altered motion rejects. Native geometry without motion retains the previous serialization and results.

All existing work ceilings remain: 120Hz physics, 54 held reaction ticks, .15 margin, 39 neutral braking ticks, 1800-tick horizon; 3072 propagations/6144 primitive queries per coordinator call, 144-call deadline, two attempts/two searches/four replays. One active/known mine maximum is enforced structurally. A rejected mine uses the existing whole independently validated ambient fallback; failed proof omits rather than force-spawns.

Production strips all DEV imports, selectors and GLB references. The GLB is deliberately under the DEV module directory, not public/. `mine-preservation.mjs` compares the production build and 76 histories against reconstructed approved sources, including 12 mixed-flow histories. Original collision, runtime and historical audits remain in the review pipeline.

Lifecycle follows the existing model, ledger, pending-session cancellation and resource ownership. Pause/focus/game over stop logical steps. Restart resets seed/history/slots/planning epoch. One reusable model instance borrows cached GLTF resources; the view owns its warning/debug meshes. Asset failure selects the existing certified mixed-flow model. No audio, HUD product design, camera, steering, native asset/profile, damage, generator or VFX change is introduced.

Evidence is generated by `mine-benchmark.mjs`, `mine-browser.mjs`, unit/browser tests and the exact-HEAD review pipeline. Reports distinguish conditional witness following, prerecorded controls and owner observations. No human acceptance or physical-phone result is claimed.
