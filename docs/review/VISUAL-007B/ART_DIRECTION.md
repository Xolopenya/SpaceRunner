# VISUAL-007B art direction

The owner approved the 007A mine, partially approved station detailing but found
it too dark, and requested a manufactured sci-fi replacement for the generic
crystal collectible. This branch inherits exact 007A `552740c3b8ae0927b2caff9c89f2fcc5b7ac897d`.
That commit's parent is RELEASE-007 follow-up `d5b02d8`; release `88c557a` is its
grandparent. Nothing is recreated from the older main.

Stations use light desaturated steel-blue cassettes against dark load-bearing
members and recessed machinery. Amber/black edges and existing cyan utility
lamps identify the real aperture. The result shares the ship/mine industrial
language without using their hazard silhouette. There are no new lights,
textures, postprocessing or station polygons.

The selected collectible is a contained energy shard: a bright turquoise
faceted core held by four angular retention shoes, with a restrained halo.
It retains the original position, animation clock, scale envelope and magnet
feedback. Beneficial cyan remains distinct from the approved mine's warning
amber and pursuit red.

All new geometry is original project-owned CC0 work. No external asset or
dependency was acquired. This is a feature review, not a public release or
owner approval of the final 007B result.
