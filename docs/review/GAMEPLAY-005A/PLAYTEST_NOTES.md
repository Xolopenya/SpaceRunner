# Playtest evidence and limits

Automated24-run corpus:8 seeds × witness/neutral/collect pilots, ending at death or2500m. All8 witness runs reach2500m with hull3. The8 optional collection pilots collect4–6 fragments each and finish with hull1–3, showing that reward pursuit can carry risk. The simulation, collision and mine metadata are not modified to force these outcomes. Full decisions, omissions, placements, timings and independent replay counts are in `logs/integrated-audit.json`.

Clean native Chrome recordings cover ordinary debris flight, a real pickup, a station opening crossing, Phase 2, a mine encounter and a boundary-orientation sequence. The clean URL has only `seed=42`; instrumentation observes the existing Game launch method and supplies recorded ordinary input axes. It never teleports the ship, inserts hazards, adds hull or bypasses publication. Each scenario uses an accelerated unrendered prefix followed by up to5seconds of visible playback at2simulation ticks per native RAF. These clips are separate excerpts, not one uninterrupted human run, and the Chrome recordings are silent.

Node/Chrome gameplay-state hashes must match at each capture. Diagnostic mine/station/boundary frames add the existing compound collider overlay. Portrait390×844 and landscape844×390 captures reproduce the same states. Viewport captures are browser emulation, not physical phone playtests. Resource checks cover10 real UI restarts without increasing GPU geometry/texture counts.

Qualitative engineering assessment: the integration retains a readable hierarchy by keeping distance/HUD unchanged, reserving mine intervals, omitting rewards in mine transactions and using sparse depth-tested edge streaks. Mines remain occasional; ordinary field and station decisions occupy most of the run. This assessment is based on replay inspection and captures, not owner approval of fun or long-term comfort.

Known risks: bounded planning can omit otherwise playable sections, creating gaps; reward approach placement is a local heuristic rather than a certified collection route; visual ship bank differs from the fixed collider profile; far portrait optics can reduce mine size; finite desktop measurements do not establish phone performance. Source edits during an initial browser pass caused HMR interruptions; that interrupted log is retained and a complete pass is run with source frozen. Legacy production assertions were updated because this feature build deliberately contains the previously experimental certified systems while still hiding DEV selectors and panels.
