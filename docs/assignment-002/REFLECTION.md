# Ответы для защиты

1. **Какое изменение было самым дорогим?** Подключение принятого процедурного поля к обычной игре вместе с новой скоростью. Недостаточно изменить число в HUD: скорость нужно согласовать с прогнозом, повтором свидетеля и моментом публикации. Поэтому release-флаг проходит от модели до FlightState и расчёта временной таблицы валидатора.

2. **Какой участок кода упрощён?** Для публичного режима повторно использован StructureVariantsView вместо отдельного рендера станций. Небольшой releaseView убирает его диагностическую панель и сохраняет bind/update/dispose. Новый контроллер или копия генератора не создавались.

3. **Что сейчас самое хрупкое?** Runtime-планирование: ограниченный поиск иногда не находит маршрут, а его порции могут давать длинные кадры. Наличие безопасного свидетеля не означает безопасность любого ввода. Homing исключён из релиза именно из-за дополнительной стоимости этой системы; физические телефоны требуют отдельной проверки.
